# Gemini Enterprise 어드민 코파일럿 비즈니스 요구 사항 명세서 (BRD)

본 문서는 사내 IT 어드민 및 클라우드 인프라 운영팀이 제미나이 엔터프라이즈 앱(Gemini Enterprise app) 운영 중 직면하는 9대 핵심 관리 과제(에이전트 및 스킬 스프롤 거버넌스 3종, 사용량 및 텔레메트리 패턴 분석 3종, 테넌트 및 네트워크 보안 3종)를 대화형으로 신속 진단하고 자율 해결할 수 있도록 지원하는 어드민 전담 코파일럿 솔루션의 비즈니스 요구 사항 명세서(Business Requirements Document)다.

---

## 1. 추진 배경 및 비즈니스 동기

1. **임직원 에이전트 및 스킬 대량 양산(Sprawl)으로 인한 공식 콘솔 거버넌스 한계**:
   - 임직원들이 자율적으로 수백, 수천 개의 노코드 에이전트와 업무 도구(스킬)를 등록하면서 공식 구글 클라우드 콘솔의 UI 목록 탐색 및 수동 필터링만으로는 물리적 통제가 불가능한 한계에 직면한다.
   - 60일 이상 호출 0건인 좀비 에이전트 방치, 사내 승인되지 않은 외부 사설 엔드포인트를 호출하는 미승인 스킬, 퇴사자나 부서 이동자의 고아(Orphan) 에이전트를 자동 식별하고 일괄 정리할 수 있는 배치 거버넌스가 절실하다.

2. **복잡한 Cloud Logging 검색 고통 없는 직관적 사용량(Usage) 패턴 분석**:
   - 부서별/계정별 토큰 소비량 톱 10 분석, 429 할당량 초과(Quota Exhaustion) 피크 시간대 추적, AI Studio 섀도우 과금 누수 탐지 시 일일이 Cloud Logging의 복잡한 LogQL 필터를 작성하고 뒤져보는 과정에 막대한 시간과 운영 공수가 소모된다.
   - 클릭 한 번 또는 자연어 질의 한 번으로 즉시 실행 가능한 정제된 BigQuery SQL 팩을 제공하여 텔레메트리 분석 공수를 제로화해야 한다.

3. **테넌트 온보딩 및 네트워크/보안 컴플라이언스 준수**:
   - 사내 대표 도메인 선점 충돌 해결, 금융권 및 대기업 보안 규정에 따른 외부 마켓플레이스 차단 및 사내 승인 강제, 와일드카드 도메인이 불허되는 폐쇄망 프록시 환경의 Exact 15대 코어 FQDN 연결성 검증을 원스톱으로 지원해야 한다.

4. **스텔스 모드(Stealth Mode) 기반의 극단적 프릭션 제거**:
   - 복잡한 보안 분기나 인프라 질문을 사용자에게 던져 인지 부하를 주지 않고, 입력이 불필요한 영역은 최적의 기본값으로 자동 직진하되, 환경 변수(프로젝트 ID, GE App ID 등) 선택지가 2개 이상일 때만 명확한 번호 선택을 제공하여 사용성을 극대화한다.

## 2. 핵심 비즈니스 요구 사항 목록 (Business Requirements)

| 요구 사항 ID | 구분 | 핵심 비즈니스 목표 및 요구 명세 |
| :--- | :--- | :--- |
| **BR-01** | 9대 엔터프라이즈 어드민 과제 카탈로그 및 자유 프롬프팅 | 사내 대표적인 9대 관리 과제(스프롤 거버넌스 3종, 사용량 패턴 분석 3종, 테넌트 및 네트워크 보안 3종) 프리셋을 제공하고, 사용자가 자유 프롬프트(`--prompt`)로 원하는 관리 이슈를 자율 진단할 수 있어야 한다. |
| **BR-02** | 사내 거버넌스 및 마켓플레이스 차단 | 외부 공개 에이전트 마켓플레이스를 전면 차단하고 사내 승인 커스텀 에이전트만 노출하는 조직 정책 매니페스트를 합성해야 한다. |
| **BR-03** | 라이선스 채택률 및 유휴 라이선스 회수 | 부서별 활성 사용자 지표를 분석하고 30일 이상 미사용 임직원의 라이선스를 자동 회수할 수 있는 분석 쿼리를 제공해야 한다. |
| **BR-04** | Overage 과금 방어 및 결제 거버넌스 | 일일 쿼터 초과 쓰로틀링을 방어하고, Google AI Studio 유료 API 키 발급을 차단하는 Billing RBAC 가이드를 도출해야 한다. |
| **BR-05** | 사내망 Exact FQDN 및 방화벽 진단 | 와일드카드 도메인이 불허되는 사내 관문 프록시(SWG) 환경에서 필수 443 포트 아웃바운드 FQDN 목록을 산출해야 한다. |
| **BR-06** | 에이전트 및 스킬 스프롤 전수 감사 | 수백 개 에이전트 및 스킬 난립 시 60일 미사용 좀비 에이전트, 미승인 외부 엔드포인트 도구, 고아 에이전트 소유권을 식별 및 이관하는 거버넌스 팩을 제공해야 한다. |
| **BR-07** | 원클릭 로그 싱크 및 콘솔 딥링크 | Cloud Logging의 감사 로그를 BigQuery로 라우팅하는 로그 싱크를 명령어 한 줄로 구축하고 GCP 콘솔 GE Admin 3단계 딥링크를 안내해야 한다. |
| **BR-08** | 대화형 추천 후속 질문 및 원클릭 리포트 | 단계별 조치를 위한 마크다운 추천 후속 질문을 출력하고 `report.md` 표준 진단 보고서를 덮어써야 한다. |
| **BR-09** | 표준 리소스 라벨링 적용 의무화 | 사내 거버넌스, FinOps 비용 배분 및 자원 추적성을 위해 리소스 생성 시 4대 표준 라벨(`managed-by`, `scenario`, `env`, `created-by`)을 필수로 주입하여야 한다. |
| **BR-10** | 선언적 어드민 레시피 아키텍처 및 케밥 케이스 표준 | 파이썬 코드 수정 없이 관리 과제를 확장할 수 있도록 선언적 카탈로그 파일(`catalog.yaml`) 분리 구조를 지원하고, 모든 과제 슬러그는 `[domain]-[target]-[action]` 형태의 3단계 소문자 케밥 케이스(kebab-case) 표준을 준수하여야 한다. |
| **BR-11** | 에어갭 및 오프라인 환경 회복 탄력성 확보 | 사내 보안 정책상 인터넷 연결이 차단된 에어갭(Air-gapped) 환경이나 외부 카탈로그 엔드포인트 장애 상황에서도 타임아웃(2.0초 이내)을 적용하고 내장된 시드 카탈로그로 원활히 폴백하여 안정적인 동작을 유지하여야 한다. |
| **BR-12** | 사전 슬러그 및 명칭 중복 검증 인터셉터 | 신규 관리 과제 등록 요청 시 사내 포털에 이미 등록된 기존 과제와의 슬러그, 디스플레이 이름 충돌 여부를 사전에 검증하여 설정 충돌 사고를 예방하여야 한다. |

## 3. 기대 효과 및 비즈니스 KPI

1. **어드민 운영 문의 대응 시간 80% 단축**: 9대 핵심 관리 이슈에 대한 원스톱 자율 진단으로 어드민의 티켓 처리 시간을 대폭 절감한다.
2. **사내 유휴 라이선스 비용 15% 이상 절감**: 미사용 라이선스를 신속하게 식별 및 회수하여 FinOps 비용 최적화를 달성한다.
3. **외부 미승인 에이전트 및 섀도우 과금 0건 달성**: 조직 정책 및 결제 거버넌스를 강화하여 엔터프라이즈 보안 무결성을 확보한다.
4. **에이전트/스킬 스프롤 및 로그 분석 공수 제로화**: 수동 콘솔 검색 및 Cloud Logging 쿼리 작성 시간을 95% 단축한다.
