  - 최적화안: 사용자 화면에 스트리밍 청크(Chunk)를 즉각 렌더링하여 엔드유저 체감 지연 최소화

종합 분석 및 아키텍처 해석:
1. [초기 토큰 수신 지연(TTFT) 격차 원인]:
   - Vertex AI 순수 API는 사전 필터나 검색 플래닝 없이 스트리밍이 즉시 시작되어 초기 토큰 도달이 빠르다.
   - Gemini Enterprise app은 Assistant 플래너(Dolphin Planner)가 쿼리 의도를 해석하고, 사내 데이터스토어 및
     구글 검색 그라운딩을 동시 탐색한 후 검색 청크를 재순위화(Reranking)하는 과정이 선행되므로 TTFT 차이가 발생한다.
2. [엔터프라이즈 신뢰 비용 (Enterprise Trust Cost)]:
   - 발생한 약 5~7초 수준의 추가 지연은 모델의 속도 결함이 아니라 환각 방지(Grounding), 출처 인용 각주 바인딩,
     사내 IAM/ACL 보안 필터링을 수행하기 위한 구조적 엔터프라이즈 거버넌스 수행 비용이다.
3. [최적화 방향]:
   - 정적 사내 규정은 데이터스토어 인덱스 캐싱을 극대화하고, 불필요한 실시간 구글 웹 검색 그라운딩은 선택적으로 비활성화한다.
   - 엔드유저 대화창에는 첫 청크 도달 전 '사내 보안 규정 검색 중...' 상태 인디케이터를 표시하여 체감 대기 시간을 완화한다.

## 4. 실습 안내 (실제 환경 실행 시 자동 덮어쓰기)

실제 Google Cloud 환경에서 본 진단을 수행하려면 아래 명령어를 실행한다.
실행 결과는 본 `report.md` 파일에 자동으로 갱신(덮어쓰기)된다:

```bash
python diagnose.py
```

## 7. 자원 정리 안내 (Teardown)

본 도구는 지연 시간 측정용 단발성 API 호출만 수행하므로 영구 인프라 자원을 생성하지 않는다.
테스트 과정에서 발급된 임시 인증 토큰은 세션 종료 시 자동으로 만료된다.
