# 비즈니스 요구 사항 명세서 (BRD): 구글 워크스페이스 마케팅 콘텐츠 파이프라인 (`gws-marketing-content-pipeline`)

## 1. 배경 및 목적
기업 및 마케팅 실무 현장에서 신제품이나 프로모션 캠페인을 론칭할 때, 마케터는 기획서 작성, 멀티 채널 카피라이팅, 비율별 비주얼 광고 소재 제작, 모바일 숏폼 영상 기획, 고객 설문 수집, 여론 분석 및 콘텐츠 수정에 이르는 복잡한 다단계 프로세스를 수작업으로 진행한다.

그러나 기존 AI 솔루션은 클라우드 프로젝트 생성, 결제 계정 승인, 파이썬 가상 환경 설정, 터미널 CLI 도구 사용, 복잡한 API Key 발급 등 높은 기술적 진입 장벽을 요구하여 비개발 직군인 마케터가 주도적으로 활용하기 어려웠다. 또한 단순 프롬프트 기반의 단발성 콘텐츠 생성은 브랜드 가이드라인과의 정합성이 떨어지고, 출시 전 다양한 타깃 오디언스의 다각적 반응을 사전 시뮬레이션하기 어려운 한계가 존재했다.

본 솔루션(`gws-marketing-content-pipeline`)은 Google Cloud 프로젝트 생성, 신용카드 등록, 복잡한 로컬 개발 환경 설정 없이, 개인 구글 계정으로 발급받는 Google AI Studio API Key 1회 등록만으로 구글 드라이브(Google Drive), 구글 시트(Google Sheets), Apps Script 상에서 브라우저 기반으로 구동되는 경량 마케팅 자동화 파이프라인을 제공한다. 마케터가 구글 드라이브에서 캠페인 폴더를 자유롭게 먼저 생성하고 그 안에 구글 시트를 넣어 시작하는 폴더 우선 UX(Folder-First UX)를 기반으로 자연어 아이디어로부터 마케팅 캠페인 기획서(PLAN), 멀티 채널 콘텐츠 제작 명세서(SPEC), 멀티 채널 마케팅 콘텐츠(카피, 이미지, 숏폼 영상)를 자동 생성하고, AI 페르소나 및 고객 동영상 VoC를 통합 분석하는 다면 평가와 인간 참여(Human-in-the-loop) 콘텐츠 보정 루프를 제공하여 비즈니스 출시 준비 시간과 리소스를 대폭 경감하는 것을 목적으로 한다.

| **BR-04** | **열린 피드백, 128d 임베딩 및 AI 페르소나 다면 평가 데이터셋 VoC 분석** | 고객 제출 모바일 동영상 피드백의 VLM 구조화 분석(15~30초 숏폼 규격)과 함께, SPEC 제약이 없는 한 열린 피드백 원칙에 따라 기본 마스터 가상 패널(25인 규격) 및 맞춤 타깃 가상 패널 전원 대상 단일 배치(Single Batch) 1회 완결 호출을 통해 풍부한 세부 의견 포인트를 도출해야 한다. Gemini 응답 오류, 객체 래핑 파싱, 또는 빈 배열(`[]`) 비정상 파일 감지 시 기본 마스터 페르소나 기반 결정론적 데이터셋으로 즉시 자가 치유(Self-Healing) 자동 복구하고 모델 미반환 페르소나를 사내 마스터 프로필 기반으로 보완(Reconciliation)하며, 한국어 특화 `text-multilingual-embedding-002` 모델의 128차원 MRL 임베딩을 통해 구조화된 AI 페르소나 피드백 데이터셋(`ai_persona_feedbacks.json`)으로 완결 제공해야 한다. | 필수 (P0) |
| **BR-05** | **인간 참여형(Human-in-the-loop) 마케팅 콘텐츠 보정 루프** | 생성된 피드백 종합 요약서(feedback_summary) 구글 독스를 브라우저에서 직접 열어 다면 평가 분석 결과를 검토한 후, 문서 하단의 마케터 최종 의사 결정 및 보정 지침 섹션을 직접 수정하거나 사이드바 8단계 인라인 상자(`directiveInlineBox`)에서 수기 지침을 즉시 입력하면, 이를 `input/fb-xx/마케터 보정 지침` 구글 독스에 자동 저장하고 반영하여 1차 개정본(rv-01) 및 N차 개정본으로 마케팅 콘텐츠를 반자율 업데이트해야 한다. | 필수 (P0) |

- **비개발자 마케팅 및 콘텐츠 기획자 (`#Marketer`, `#Architect`)**: 인프라 승인 대기나 복잡한 개발 도구 없이 실무 현장에서 즉시 생성형 AI를 활용하여 브랜드 캠페인 기획부터 멀티 채널 콘텐츠 제작, 가상 평가를 원스톱으로 수행하고자 하는 실무 마케터
- **크리에이티브 및 콘텐츠 제작자 (`#Developer`)**: 기획서와 시스템 규격에 정렬된 일관된 멀티 채널 카피라이팅, 다중 해상도 그래픽, 모바일 숏폼 영상 콘티 및 광고 소재를 효율적으로 생성하고자 하는 담당자

## 4. 향후 확장 및 고려 사항 (Future Considerations)

- **대규모 캠페인 원천 자산 질의 및 컨텍스트 캐싱(Context Caching) 확장 고려**:
  - **현재 경량 관제 체계**: 사이드바 AI 코파일럿은 파이프라인의 실시간 상태 메타데이터(URL, 폴더, 상태 식별자 등 약 500~800 토큰)를 기반으로 동작하며, Apps Script의 30초 로컬 사용자 캐시(`CacheService`)를 통해 구글 드라이브 스캔 횟수와 지연 시간을 최소화하고 Google AI Studio API Key 단독으로 구동된다.
  - **대형화 시 확장 검토 (Scale-up Pathway)**:
    - 향후 캠페인 기획서(PLAN), 제작 명세서(SPEC), 타깃 AI 페르소나 패널, 브랜드 가이드라인(톤앤매너, 금지어, 컬러 팔레트) 및 과거 누적 캠페인 이력 등 대규모 비정형 문서 전문을 코파일럿 대화 컨텍스트에 직접 주입(Full Context Injection, 10,000~50,000+ 토큰)하는 '캠페인 자산 인텔리전스(Campaign Asset Intelligence)'로 확장할 경우,
    - Gemini API 공식 Context Caching(`v1beta/cachedContents`) 또는 버텍스 AI(Vertex AI) 검색 및 RAG 파이프라인 도입을 검토한다.
    - 단, 공식 Context Caching 도입 시 유료 결제 계정 연결(스토리지 보관료 발생) 및 마케터 문서 수정 시 캐시 무효화(Cache Invalidation) 수명 주기 관리가 수반되므로, 초기에는 Flash 모델의 1M 토큰 윈도우 다이렉트 추론 방식을 우선 채택하고 엔터프라이즈 브랜드 자산 대형화 시점에 캐싱을 정식 고려한다.
