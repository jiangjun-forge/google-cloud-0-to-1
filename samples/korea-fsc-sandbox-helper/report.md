## 5. 서울 리전(`asia-northeast3`) 금융 AI 망 분리 샌드박스 참조 블루프린트

1. **망 분리 대체 논리적 격리 및 비공개 전용 통신 (`asia-northeast3`)**:
   - 사내 업무망/전산망(On-Premises)과 GCP 금융 샌드박스 프로젝트(`sample-project-id`) 간 Dedicated Interconnect 및 Private Service Connect(PSC) 엔드포인트를 구성하여 공중 인터넷 경로를 원천 배제한다 (`technical_security:1:1~2:3` 충족).
   - 조직 정책(`constraints/compute.vmExternalIpAccess`)으로 모든 워크로드의 공인 IP 할당을 차단한다.
2. **가상 보안 경계(VPC-SC Enforced) 및 입출력 가드레일 결합**:
   - Vertex AI, BigQuery, Cloud Storage, Cloud KMS를 단일 VPC Service Controls(Enforced 모드) 보안 경계로 묶어 외부 프로젝트로의 데이터 반출을 차단한다 (`technical_security:3:1~3:3` 충족).
   - 프롬프트 전송 전 Sensitive Data Protection(Cloud DLP)으로 개인 신용 정보를 가명/익명화하고, Model Armor로 프롬프트 인젝션 및 유해 응답을 실시간 살균한다 (`consumer_benefit:3:1` 충족).
3. **금융회사 직접 통제 암호화(Cloud HSM CMEK), 2년 불변 감사 로깅(WORM) 및 국내 DR**:
   - 서울 리전(`asia-northeast3`) Cloud HSM 기반 CMEK 키를 바인딩하여 전자금융감독규정 제37조 암호 키 직접 통제권 요건을 충족한다 (`technical_security:5:1~5:3` 충족).
   - 모든 관리자 행위, 데이터 접근(Data Access), Gemini 프롬프트/응답 이력을 Bucket Lock(730일 Retention)이 걸린 서울 리전 불변 스토리지에 강제 싱크하고(`technical_security:6:1~6:3` 충족), 실증 한도 90% 도달 시 자동 서킷 브레이커(Circuit Breaker)를 발동한다 (`regulatory_necessity:2:1~2:3` 충족).

## 7. 물적 설비 및 논리적 망 분리 즉시 조치 명령어 (4대 필수 라벨 포함)

금융보안원 보안성 심의에서 반려 빈도가 가장 높은 **CMEK 암호 키 직접 통제권(`technical_security:5:2~5:3`)**, **감사 로그 2년 WORM 불변 잠금(`technical_security:6:1`)**, **실증 한도 90% 경보 토픽(`regulatory_necessity:2:3`)**을 서울 리전(`asia-northeast3`)에 즉시 구성하는 표준 명령어다.

```bash
# 1. 서울 리전(asia-northeast3) Cloud HSM 기반 고객 관리 암호화 키(CMEK) 생성 및 4대 표준 라벨 부여
gcloud kms keyrings create fsc-sandbox-keyring \
  --location=asia-northeast3 \
  --project=sample-project-id

gcloud kms keys create fsc-ai-cmek-key \
  --keyring=fsc-sandbox-keyring \
  --location=asia-northeast3 \
  --purpose=encryption \
  --protection-level=hsm \
  --rotation-period=90d \
  --next-rotation-time=$(date -u -d '+90 days' +%Y-%m-%dT%H:%M:%SZ) \
  --labels=managed-by=google-cloud-0-to-1,scenario=korea-fsc-sandbox-helper,env=sample,created-by=customer-engineer \
  --project=sample-project-id

# 2. 감사 로그 및 프롬프트 이력 2년(730일) 불변 보존(WORM Bucket Lock) 버킷 생성
gcloud storage buckets create gs://sample-project-id-fsc-audit-worm \
  --location=asia-northeast3 \
  --uniform-bucket-level-access \
  --public-access-prevention \
  --retention-period=730d \
  --default-encryption-key=projects/sample-project-id/locations/asia-northeast3/keyRings/fsc-sandbox-keyring/cryptoKeys/fsc-ai-cmek-key \
  --labels=managed-by=google-cloud-0-to-1,scenario=korea-fsc-sandbox-helper,env=sample,created-by=customer-engineer \
  --project=sample-project-id

# 3. 실증 한도(Cap) 90% 도달 및 서킷 브레이커 발동 알림용 Pub/Sub 토픽 생성
gcloud pubsub topics create fsc-sandbox-circuit-breaker-alerts \
  --labels=managed-by=google-cloud-0-to-1,scenario=korea-fsc-sandbox-helper,env=sample,created-by=customer-engineer \
  --project=sample-project-id
```
