# 비즈니스 요구 사항 명세서 (BRD): 구글 드라이브 마케팅 콘텐츠 파이프라인 (`drive-marketing-content-pipeline`)

## 1. 배경 및 목적
기업 및 마케팅 실무 현장에서 신제품이나 프로모션 캠페인을 론칭할 때, 마케터는 기획서 작성, 멀티 채널 카피라이팅, 비율별 비주얼 광고 소재 제작, 모바일 숏폼 영상 기획, 고객 설문 수집, 여론 분석 및 콘텐츠 수정에 이르는 복잡한 다단계 프로세스를 수작업으로 진행한다.

그러나 기존 인공 지능 솔루션은 클라우드 프로젝트 생성, 결제 계정 승인, 파이썬 가상 환경 설정, 터미널 CLI 도구 사용, 복잡한 API Key 발급 등 높은 기술적 진입 장벽을 요구하여 비개발 직군인 마케터가 주도적으로 활용하기 어려웠다. 또한 단순 프롬프트 기반의 단발성 콘텐츠 생성은 브랜드 가이드라인과의 정합성이 떨어지고, 출시 전 다양한 타깃 오디언스의 다각적 반응을 사전 시뮬레이션하기 어려운 한계가 존재했다.

본 솔루션(`drive-marketing-content-pipeline`)은 Google Cloud 프로젝트 및 복잡한 로컬 개발 환경, 별도 API Key 발급 절차 없이, 현재 로그인된 구글 계정 OAuth 2.0 자동 인증(Keyless Zero-Setup)만으로 구글 드라이브, 구글 시트, Apps Script 상에서 100% 브라우저 기반으로 구동되는 경량 마케팅 자동화 파이프라인을 제공한다. 자연어 아이디어로부터 마케팅 캠페인 기획서(PLAN), 멀티 채널 콘텐츠 제작 명세서(SPEC), 멀티 채널 마케팅 콘텐츠(카피, 이미지, 숏폼 영상)를 자동 양산하고, 25인 AI 페르소나 및 고객 동영상 VoC를 통합 분석하는 다면 평가와 인간 참여(Human-in-the-loop) 콘텐츠 보정 루프를 제공하여 비즈니스 출시 준비 시간과 리소스를 대폭 경감하는 것을 목적으로 한다.

## 2. 핵심 비즈니스 요구 사항 (Business Requirements)

| 요구 사항 ID | 요구 사항 명칭 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :--- |
| **BR-01** | **인프라 종속성 및 API Key 제거 (Zero-GCP & Keyless Zero-Setup)** | 별도의 Google Cloud 결제 프로젝트나 로컬 파이썬 개발 환경, API Key 발급 절차 없이, 브라우저 상의 구글 시트와 구글 계정 로그인 권한 단독으로 전체 9단계(Step 1~Step 9) 자동화 파이프라인이 완전 구동되어야 한다. | 필수 (P0) |
| **BR-02** | **명세 기반 멀티 채널 마케팅 콘텐츠 및 소재 자동 양산** | 자연어 아이디어로부터 마케팅 캠페인 기획서(PLAN) 및 멀티 채널 콘텐츠 제작 명세서(SPEC) 구글 독스를 자동 생성하고, 마케터가 브라우저에서 직접 수정한 SPEC 규격(이미지 비율, 숏폼 영상 길이, 카피 채널)에 기반하여 카피, 비율별 비주얼 소재(16:9, 9:16, 1:1), 세로 9:16 모바일 숏폼 영상을 체계적으로 양산해야 한다. | 필수 (P0) |
| **BR-03** | **타깃 AI 페르소나 패널 및 맞춤 재설정** | 대한민국 시장 환경을 반영한 25인 마스터 가상 평가단을 제공해야 하며, 마케터가 특정 캠페인 타깃(예: 특정 연령대, 국가, 직업군)을 자연어로 입력하거나 외부 데이터셋을 지정할 경우 실시간으로 페르소나 패널을 맞춤 재구성할 수 있어야 한다. | 필수 (P0) |
| **BR-04** | **열린 피드백, 128d 임베딩 t-SNE 지형도 및 비디오 VoC 분석** | 고객 제출 모바일 동영상 피드백의 VLM 구조화 분석(15~30초 숏폼 규격)과 함께, SPEC 제약이 없는 한 열린 피드백 원칙에 따라 25인 페르소나로부터 50~80개 이상의 세부 의견 포인트를 도출하고, 한국어 특화 `text-multilingual-embedding-002` 모델의 128차원 MRL 임베딩을 통해 QuickChart 기반 2D t-SNE 여론 지형도로 시각화해야 한다. | 필수 (P0) |
| **BR-05** | **인간 참여형(Human-in-the-loop) 마케팅 콘텐츠 보정 루프** | 다면 평가 결과 보고서를 검토한 마케터가 브라우저 대화 상자에서 최종 보정 지침을 결정하면, 이를 반영하여 1차 개정본(rv-01) 및 2차 완결본(rv-02)으로 마케팅 콘텐츠를 반자율 업데이트해야 한다. | 필수 (P0) |
| **BR-06** | **실시간 진행 대시보드 및 원클릭 접근성** | Google Sheets 내 `실행 대시보드` 탭을 통해 전체 9단계 처리 상태와 Google Drive에 생성된 산출물(PLAN, SPEC, 콘텐츠 폴더, Google Forms, 피드백 보고서)의 하이퍼링크를 즉시 제공하여 사용자 편의성을 확보해야 한다. | 권장 (P1) |
| **BR-07** | **비디오 처리 제약 방어 및 Google Cloud 엔터프라이즈 확장 경로** | Apps Script의 런타임 제약(6분 타임아웃, 50MB 페이로드)에 따라 브라우저 내에서는 숏폼 동영상(30MB 이하)으로 안정성을 보장하며, 장시간 심층 인터뷰 등 엔터프라이즈 규모 분석이 필요한 경우 Google Cloud 환경으로의 이관을 위해 Google Cloud에 연락하여 전문 컨설팅을 받도록 안내해야 한다. | 권장 (P1) |
| **BR-08** | **고객 제출 이미지 VLM 시각 분석 및 수작업 투입 자료 전수 스캔** | Google Forms를 통해 접수된 고객 제출 이미지(착용 샷, 디자인 등)를 Gemini VLM으로 시각 분석하고, 폼을 거치지 않고 마케터가 `input/fb-xx/` 폴더에 직접 수작업으로 드롭한 파일(이미지, 추가 영상, 메모 문서)도 전수 자동 감지 및 병합하여 다면 평가와 차기 리비전의 정밀한 근거로 반영해야 한다. | 필수 (P0) |
| **BR-09** | **99차 무제한 피드백 루프 및 비차단 대기 안내 UX (Toast Alert)** | 피드백 수집과 콘텐츠 개정 루프가 단발성 2회차에 머무르지 않고 `fb-01`~`fb-99`, `rv-00`~`rv-99`까지 자동 증가 및 수기 지정 방식으로 자유롭게 순환할 수 있어야 하며, 장시간 소요 작업 시 Google Sheets 비차단 토스트로 예상 소요 시간을 즉시 안내하여 사용자 대기 불안감을 해소해야 한다. | 필수 (P0) |
| **BR-10** | **종단간 에뮬레이션 단위 테스트 수이트 (All & Unit Execution)** | 실제 클라우드 API 호출이나 비용 소모 없이 파이프라인의 8대 핵심 기능(설정, 유틸리티, 동적 회차 탐색, VLM/수작업 스캐너, 페르소나 데이터셋, 설문/평가 가중치, 마케터 HITL 보정, Hugging Face 연동 규격)을 100% 모의(Mocking) 검증할 수 있어야 하며, Google Sheets 메뉴 및 로컬 터미널에서 전체 일괄 실행(`All`)과 개별 단위 테스트 단독 실행을 모두 지원해야 한다. | 필수 (P0) |

## 3. 대상 독자 및 이해관계자 (Target Audience)
- **마케팅 및 콘텐츠 기획자 (`#Architect`)**: 인프라 승인 대기 없이 실무 현장에서 즉시 생성형 인공 지능을 활용하여 브랜드 캠페인 콘텐츠를 원스톱으로 제작하고 사전 검증을 수행하고자 하는 실무 총괄자
- **크리에이티브 및 콘텐츠 제작자 (`#Developer`)**: 기획서와 시스템 규격에 정렬된 일관된 멀티 채널 카피라이팅, 다중 해상도 그래픽, 모바일 숏폼 영상 콘티 및 광고 소재를 효율적으로 양산하고자 하는 담당자
- **퍼포먼스 마케터 및 데이터 분석가 (`#FinOps`, `#SecOps`)**: 25인 가상 소비자 페르소나 반응 및 고객 동영상 VoC를 정량, 정성적으로 통합 분석하고 t-SNE 여론 지형도를 통해 메시지 반응도를 사전에 정밀 측정하고자 하는 실무자
