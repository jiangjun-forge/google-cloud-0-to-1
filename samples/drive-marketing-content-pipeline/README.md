# 구글 드라이브(Google Drive) 마케팅 콘텐츠 생성 파이프라인 (`drive-marketing-content-pipeline`)

구글 클라우드(Google Cloud) 프로젝트 생성 및 복잡한 로컬 파이썬 개발 환경 설정, 별도 API Key 발급 없이, 현재 로그인된 구글 계정 OAuth 2.0 자동 인증(Keyless Zero-Setup)만으로 구글 드라이브(Google Drive), 구글 시트(Google Sheets), Apps Script 기반의 종단간 마케팅 콘텐츠 양산 및 25인 AI 페르소나 다면 평가 파이프라인을 구축하는 경량 자동화 솔루션이다. (As of 2026-10-13)

**Audience**: `#Architect`, `#Developer`  
**Concern**: `#Performance`, `#Resilience`  
**Service**: `#GeminiAPI`, `#Workspace`

---

## 문제 증상 체크리스트

- 구글 클라우드 프로젝트 승인이나 파이썬 개발 환경 없이 브라우저에서 AI 마케팅 자동화를 즉시 검증하고 싶을 때
- 신제품 출시 전 25인 다면 소비자 반응 및 정량 평점, 정성 의견, 이미지/비디오 VoC를 사전 통합 분석하고 싶을 때
- 단순 1회성 생성을 넘어, 기획서(PLAN)와 제작 명세서(SPEC)에 맞춘 엄격한 콘텐츠 양산 및 마케터 피드백 보정 루프가 필요할 때

## 가이드

### 1단계: 구글 시트 생성 및 번들 스크립트 붙여넣기
1. 구글 드라이브 ( https://drive.google.com )에서 빈 구글 시트(Google Sheets) 문서를 새로 생성한다.
2. 상단 메뉴에서 `확장 프로그램` > `Apps Script`를 클릭한다.
3. 기본 편집창의 기존 코드를 모두 지우고, 본 저장소의 [bundle_apps_script.js](bundle_apps_script.js) 파일 내용을 전체 복사하여 붙여넣는다.
4. 좌측 `프로젝트 설정 (톱니바퀴 아이콘)`에서 `편집기에서 "appsscript.json" 매니페스트 파일 표시`를 체크한 뒤, 본 저장소의 [appsscript.json](appsscript.json) 파일 내용을 붙여넣고 상단 디스크 아이콘(`프로젝트 저장`)을 누른다.
5. 구글 시트 브라우저 탭을 새로고침(F5)하면 상단 메뉴 바에 `[마케팅 콘텐츠 파이프라인]` 커스텀 메뉴가 활성화된다.

### 2단계: 상단 메뉴를 통한 9단계 자동화 순차 실행

1. `[Step 1] Google Drive 작업 공간 및 25인 페르소나 자동 생성`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 1] Google Drive 작업 공간 및 25인 페르소나 자동 생성`을 클릭한다.
   - 클릭 1번으로 구글 드라이브에 캠페인 루트 폴더(`cp-ignite`), 25인 페르소나 데이터셋(`input/ai_personas.json`), 비디오 샘플을 자동 세팅한다.
   - 최초 1회 실행 시 구글 계정 권한 승인 팝업이 나타나면 `고급` > `이동`을 클릭한 후 `허용`을 선택한다. (구글 계정 자동 로그인으로 완결 구동)
2. `[Step 2] 아이디어 기반 기획서(PLAN) 및 콘텐츠 제작 명세서(SPEC) 자동 도출`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 2] 아이디어 기반 기획서(PLAN) 및 콘텐츠 명세서(SPEC) 자동 도출`을 클릭한다.
   - 캠페인 아이디어(예: '프리미엄 노이즈 캔슬링 헤드폰 가을 론칭 프로모션')를 자유롭게 입력하면 전문 마케팅 캠페인 기획서(`PLAN`)와 멀티 채널 콘텐츠 제작 명세서(`SPEC`) 구글 독스(Google Docs) 문서가 자동 생성된다. 마케터는 브라우저에서 직접 `SPEC` 수치(이미지 비율, 숏폼 길이, 카피 채널)를 수정할 수 있다.
3. `[Step 3] 기획서(PLAN) 및 명세서(SPEC) 기반 초판 마케팅 콘텐츠 양산 (rv-00)`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 3] 기획서 및 명세서 기반 초판 마케팅 콘텐츠 양산 (rv-00)`을 클릭한다.
   - 마케터가 확정한 `SPEC` 규격에 맞추어 마케팅 카피 구글 독스(`campaign_content`), 대표 비주얼 이미지 3종 비율 세트(16:9, 9:16, 1:1), 세로 9:16 모바일 숏폼 영상(`00_shorts.mp4`)을 콘텐츠 폴더에 자동 일괄 양산한다.
4. `[Step 4] 고객 VoC 수집용 Google Forms 자동 생성 (이미지/비디오 업로드)`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 4] 고객 VoC 수집용 Google Forms 자동 생성 (이미지/비디오 업로드)`를 클릭한다.
   - 평점, 서술형 의견, 고객 동영상 및 이미지 첨부 문항이 포함된 구글 폼(Google Forms) 문서를 생성하고 구글 시트 응답 탭 및 모바일 접속용 QR 코드를 자동 연동한다. (동영상 업로드 권장 규격: 15초~30초 이내 숏폼 영상, 파일 크기 30MB 이하)
5. `[Step 5] 25인 AI 페르소나 1차 다면 평가 및 t-SNE 지형도 자동 렌더링 (fb-01)`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 5] 25인 AI 페르소나 1차 다면 평가 및 t-SNE 지형도 자동 렌더링 (fb-01)`을 클릭한다.
   - 25인의 가상 소비자 반응, 설문 제출 이미지 및 비디오 VoC VLM 분석 결과, 그리고 마케터가 `input/fb-01/` 폴더에 직접 드롭한 수작업 투입 자료(이미지, 추가 영상, 메모 문서)를 종합 병합하여 t-SNE 여론 지형도가 임베드된 다면 평가 보고서(`feedback_summary`) 구글 독스 문서를 완성한다.
6. `[Step 6] 마케터 피드백 검토 및 최종 의사 결정 (Human-in-the-loop)`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 6] 마케터 피드백 검토 및 최종 의사 결정 (Human-in-the-loop)`을 클릭한다.
   - 마케터 전용 팝업이 표시되며, 평가 보고서를 검토한 마케터가 핵심 개선 방향을 선택하거나 직접 입력하여 최종 보정 지침을 확정한다.
7. `[Step 7] 다면 평가 피드백 기반 1차 마케팅 콘텐츠 반자율 보정 (rv-01)`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 7] 다면 평가 피드백 기반 1차 마케팅 콘텐츠 반자율 보정 (rv-01)`을 클릭한다.
   - 마케터의 의사 결정과 시각적 피드백을 반영하여 개정된 광고 카피, 새로운 이미지 3종, 보정된 모바일 숏폼 영상이 담긴 `rv-01/` 마케팅 콘텐츠를 자동 제작한다.
8. `[Step 8] 다면 평가 및 t-SNE 지형도 갱신 (N차 피드백: fb-02 ~ fb-99)`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 8] 다면 평가 및 t-SNE 지형도 갱신 (N차 피드백: fb-02 ~ fb-99)`를 클릭한다.
   - 대화형 다이나믹 런처가 구동되어 최신 폴더를 자동 스캔한 뒤 다음 피드백 회차(기본값: `fb-02`)를 제안하며, 빈칸으로 확인 시 자동 증분되고 원하는 번호(`3`, `07`, `99` 등)를 수기 지정할 수도 있다. 실행 즉시 화면 우측 하단에 예상 소요 시간(약 45초~1분 30초) 토스트 안내가 표시된다.
9. `[Step 9] 마케팅 콘텐츠 반자율 보정 (N차 리비전: rv-02 ~ rv-99)`:
   - 구글 시트 상단 메뉴에서 `[마케팅 콘텐츠 파이프라인]` > `[Step 9] 마케팅 콘텐츠 반자율 보정 (N차 리비전: rv-02 ~ rv-99)`를 클릭한다.
   - 대화형 다이나믹 런처를 통해 최신 리비전을 자동 감지하여 다음 개정본(기본값: `rv-02`)을 자동 양산하거나 마케터가 원하는 번호로 점프할 수 있다. 완결 카피, 신규 비주얼 3종 및 숏폼 영상을 일괄 패키징하며, 실행 즉시 비차단 소요 시간 토스트 안내가 제공된다.

> [!TIP]
> **타깃 AI 페르소나 맞춤 변경 (선택 사항)**:
> 상단 메뉴의 `[마케팅 콘텐츠 파이프라인]` > `[0. 타깃 AI 페르소나 패널 맞춤 재설정 (선택 사항)]`을 클릭하여 원하는 타깃 시장(예: '일본 20대 여성', '미국 B2B SaaS 바이어' 또는 'hf:데이터셋명')을 입력하면 해당 캠페인 전용 25인 맞춤 평가단으로 즉시 교체된다.

## 생성 산출물 디렉터리 구조

파이프라인 실행 시 구글 드라이브(My Drive) 루트에 다음과 같은 자체 완결적 폴더 구조가 가나다순 및 알파벳순으로 자동 구축된다:

```text
My Drive/
├── 마케팅 콘텐츠 파이프라인 (구글 시트: 9단계 자동화 컨트롤 타워)
└── cp-ignite/ (캠페인 루트 작업 폴더)
    ├── 고객 피드백 설문 (구글 폼: 실시간 고객 VoC 수집 폼)
    ├── input/ (원천 입력 데이터셋)
    │   ├── 아이디어 메모 (구글 독스: 마케터 캠페인 아이디어 초안 메모)
    │   ├── ai_personas.json (해당 캠페인 전용 25인 슬림 페르소나 패널)
    │   ├── fb-01/ (1차 피드백 데이터셋)
    │   │   ├── ai_persona_feedbacks.json (25인 페르소나 실시간 평가 데이터)
    │   │   ├── feedback_clusters_map.png (text-multilingual-embedding-002 기반 128d t-SNE 지형도)
    │   │   ├── feedback_points_128d.json (128d 임베딩 투영 세부 의견 포인트 목록)
    │   │   ├── feedback_sample.mp4 (고객 직접 촬영 모바일 세로 비디오 VoC)
    │   │   ├── feedback_summary (구글 독스: VLM 분석과 지형도가 포함된 종합 다면 평가 보고서)
    │   │   └── video_voc_analysis.json (Gemini VLM 멀티모달 표정, 음성 톤, 발화 분석 결과)
    │   └── fb-02/ (2차 피드백 데이터셋: N차 루프 시 자동 생성)
    ├── output/ (리비전별 마케팅 콘텐츠)
    │   ├── rv-00/ (초판 마케팅 콘텐츠)
    │   │   ├── 00_banner_16x9.png (가로형 디스플레이 배너 16:9)
    │   │   ├── 00_poster_9x16.png (세로형 모바일 포스터 9:16)
    │   │   ├── 00_shorts.mp4 (세로 9:16 모바일 숏폼 영상)
    │   │   ├── 00_sns_1x1.png (정방형 SNS 피드 이미지 1:1)
    │   │   └── campaign_content (구글 독스: 멀티 채널 카피 및 영상 콘티)
    │   ├── rv-01/ (1차 개정본: 피드백 반영 카피, 신규 비주얼 3종, 숏폼 영상)
    │   └── rv-02/ (2차 완결본: 최종 완결형 콘텐츠 번들)
    ├── PLAN (구글 독스: 마케팅 캠페인 기획서 전문)
    └── SPEC (구글 독스: 멀티 채널 콘텐츠 제작 명세서 - 이미지, 숏폼, 카피 규격)
```

## 실습 유의 사항: 비디오 분석 권장 규격 및 클라우드 이관 안내

> [!WARNING]
> - **숏폼 동영상 권장 규격**: 브라우저 서버리스 환경(Apps Script 런타임 제약 및 페이로드 한계)의 안정적인 구동을 위해 **15초~30초 이내의 숏폼 동영상(파일 크기 30MB 이하)** 업로드를 권장한다.
> - **구글 클라우드 환경 이관**: 1분 이상의 장문 고객 인터뷰 영상이나 고화질 대용량 동영상을 다루고자 할 때는 구글 클라우드 환경으로의 이관이 필요하며, 성공적인 이관을 위해 구글 클라우드에 연락하여 전문 컨설팅을 받는 것을 권장한다.

## 자원 정리 안내 (Teardown)

본 솔루션은 유료 클라우드 리소스를 일절 생성하지 않는다. 실습 및 검증을 완료한 후 정리하고자 할 경우 다음 절차를 수행한다:

1. **구글 드라이브 산출물 삭제**:
   - 구글 드라이브 ( https://drive.google.com )에서 생성된 캠페인 루트 폴더(`cp-ignite`)와 구글 시트 문서를 휴지통으로 이동 후 비운다.
